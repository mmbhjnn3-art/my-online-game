بسته نصب اعلان‌های خارج از بازی — زندگی مجازی

فایل‌هایی که باید در ریشه مخزن GitHub قرار بگیرند:
- index.html       نسخه بازی با فعال‌سازی اعلان و پنل پیام سازنده
- server.py        سرور بازی با ثبت اشتراک و ارسال اعلان به کاربران خارج از بازی
- sw.js            دریافت و نمایش اعلان در پس‌زمینه
- requirements.txt وابستگی‌های کامل پروژه، شامل وابستگی اعلان

نصب در GitHub:
1) از فایل‌های فعلی پروژه نسخه پشتیبان بگیر.
2) index.html و server.py را با فایل‌های همین بسته جایگزین کن.
3) sw.js را در همان پوشه اصلی (کنار index.html و server.py) بارگذاری کن.
4) requirements.txt همین بسته را جایگزین requirements.txt فعلی کن؛ این فایل شامل هر سه وابستگی قبلی تو و pywebpush است.
5) فایل‌های اضافی مثل README-FA.txt برای اجرای برنامه ضروری نیستند.

تنظیم Render (ضروری):
در سرویس Render به Environment برو و این سه متغیر را بساز:
- VAPID_PUBLIC_KEY = مقدار PUBLIC_KEY از فایل کلیدهای جداگانه
- VAPID_PRIVATE_KEY = مقدار PRIVATE_KEY از فایل کلیدهای جداگانه
- VAPID_SUBJECT = https://my-online-game-67j9.onrender.com
سپس Save Changes و Deploy را انجام بده.

مهم: فایل کلید خصوصی را به GitHub اضافه نکن. فقط مقدار آن را در Environment رندر قرار بده.

فعال‌سازی برای بازیکنان:
هر بازیکن باید با مرورگر سازگار و آدرس HTTPS وارد حسابش شود، گزینه «فعال‌سازی اعلان‌های خارج از بازی» را بزند و اجازه اعلان را بدهد. اجازه اعلان برای هر دستگاه/مرورگر جداگانه است.

رفتار اعلان‌ها:
- با پایان تایمر اطلاعیه بروزرسانی، اعلان پایان بروزرسانی برای مشترکانی که داخل بازی نیستند فرستاده می‌شود.
- فقط سازنده‌ای که نشست معتبر ابزار ساخت را فعال کرده، می‌تواند متن اعلان دستی بنویسد و ارسال کند.
- پیام دستی برای مشترکان خارج از بازی ارسال می‌شود؛ متن پیام همان متن واردشده است.
- برای دریافت اعلان، کاربر باید قبلاً اعلان‌ها را فعال کرده باشد.

نکات:
- Push در Chrome اندروید و مرورگرهای سازگار با Push API کار می‌کند؛ بعضی WebViewها پشتیبانی نمی‌کنند.
- اگر Render رایگان به‌خاطر بی‌فعالیتی متوقف شود، اجرای اعلان پایان تایمر ممکن است تا بیدار شدن سرویس به تأخیر بیفتد.
- دیتابیس فعلی را پاک نکن؛ سرور جدول‌های لازم اعلان را ایجاد/تکمیل می‌کند.
